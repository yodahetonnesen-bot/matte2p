## Prosentregning

::regel Tre grunnoppgaver
$$p\,\%\ \text{av tallet} = \frac{p}{100}\cdot\text{hele tallet}\qquad \text{prosent} = \frac{\text{delen}}{\text{det hele}}\cdot 100\,\%\qquad \text{det hele} = \frac{\text{delen}}{p}\cdot 100$$
::

## Prosentpoeng

::regel Prosentpoeng og prosent
Endring i **prosentpoeng** = differansen mellom to prosenttall.
Endring i **prosent** = $\dfrac{\text{endringen}}{\text{utgangsverdien}}\cdot 100\,\%$.

Fra 6 % til 9 %: opp 3 prosentpoeng, som er 50 %.
::

## Vekstfaktor

::regel Vekstfaktor
$$\text{økning på } p\,\%:\ 1 + \frac{p}{100}\qquad \text{nedgang på } p\,\%:\ 1 - \frac{p}{100}$$
$$\text{ny verdi} = \text{opprinnelig verdi}\cdot\text{vekstfaktor}$$
$$\text{vekstfaktor} = \frac{\text{ny verdi}}{\text{opprinnelig verdi}}\qquad \text{opprinnelig verdi} = \frac{\text{ny verdi}}{\text{vekstfaktor}}$$
::

Flere endringer etter hverandre: **gang** vekstfaktorene. Prosentene kan ikke legges sammen.

## Eksponentiell vekst

::regel Verdien etter $n$ perioder
$$\text{opprinnelig verdi}\cdot(\text{vekstfaktor})^n$$
Negativ $n$ gir verdien $n$ perioder *tilbake* i tid.
::

## Eksponentielle modeller

::regel Eksponentialfunksjon
$$f(x) = a\cdot k^x$$
$a$ er verdien når $x = 0$, og $k$ er vekstfaktoren. Med **regresjon** finner vi den eksponentialfunksjonen som passer best med et datasett. Vurder alltid hvor godt modellen passer, og vær forsiktig med å bruke den langt utenfor dataene.
::

| Vekstfaktor $k$ | Betyr | Grafen |
|---|---|---|
| $k > 1$ | $(k - 1)\cdot 100\,\%$ økning per periode | stiger stadig brattere |
| $k = 1$ | ingen endring | vannrett |
| $0 < k < 1$ | $(1 - k)\cdot 100\,\%$ nedgang per periode | synker og flater ut mot 0 |
