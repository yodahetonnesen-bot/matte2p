## 6.12 @6.1
Forklar hvorfor trekantene er formlike.
a) I $\triangle ABC$ er $\angle A = 60^\circ$ og $\angle B = 55^\circ$. I $\triangle PQR$ er $\angle P = 55^\circ$ og $\angle Q = 65^\circ$.
>> $\angle C = 180^\circ - 60^\circ - 55^\circ = 65^\circ$. Da har begge trekantene vinklene $55^\circ$ og $65^\circ$ ($\angle B = \angle P$ og $\angle C = \angle Q$), så de er formlike.
b) I $\triangle ABC$ er $\angle A = 42^\circ$ og $\angle C = 75^\circ$. I $\triangle PQR$ er $\angle P = 42^\circ$ og $\angle Q = 63^\circ$.
>> $\angle B = 180^\circ - 42^\circ - 75^\circ = 63^\circ$. Da er $\angle A = \angle P$ og $\angle B = \angle Q$, så trekantene er formlike.
