**Spredningsmål** forteller hvor mye observasjonene varierer.

## Variasjonsbredde

::def Variasjonsbredde
$$\text{variasjonsbredde} = \text{største verdi} - \text{minste verdi}$$
::

::eks Sju elever løp 60 m på 9,2 s, 8,7 s, 9,5 s, 8,2 s, 8,9 s, 8,5 s og 9,3 s. Finn variasjonsbredden.
---
$9{,}5\ \text{s} - 8{,}2\ \text{s} = \underline{\underline{1{,}3\ \text{s}}}$
::

::obs Svakheten ved variasjonsbredden
Den bruker bare de to mest ekstreme verdiene. Én uvanlig verdi (for eksempel en buss som er 20 minutter forsinket én dag) gir stor variasjonsbredde selv om resten er helt jevnt.
::

## Standardavvik

::regel Standardavvik
$$\sigma = \sqrt{\frac{(x_1 - g)^2\cdot f_1 + (x_2 - g)^2\cdot f_2 + \ldots + (x_n - g)^2\cdot f_n}{N}}$$
der $g$ er gjennomsnittet og $N$ antall observasjoner. Uttrykket under rottegnet er **variansen**.
::

Standardavviket tar hensyn til **alle** verdiene. Det er et slags «gjennomsnittlig avstand» fra gjennomsnittet.

::eks Finn gjennomsnittet og standardavviket for løpetidene over.
---
$g = \frac{62{,}3}{7} = 8{,}9$ s.

| $x$ | $x - g$ | $(x - g)^2$ |
|---|---|---|
| 9,2 | 0,3 | 0,09 |
| 8,7 | −0,2 | 0,04 |
| 9,5 | 0,6 | 0,36 |
| 8,2 | −0,7 | 0,49 |
| 8,9 | 0 | 0 |
| 8,5 | −0,4 | 0,16 |
| 9,3 | 0,4 | 0,16 |
| **Sum** | | **1,30** |

$$\sigma = \sqrt{\frac{1{,}30}{7}} \approx \underline{\underline{0{,}43\ \text{s}}}$$

I regneark: `=GJENNOMSNITT(A1:G1)` og `=STDAV.P(A1:G1)`.

Fra $8{,}9 - 0{,}43 = 8{,}47$ til $8{,}9 + 0{,}43 = 9{,}33$ ligger 5 av 7 tider, altså omtrent 70 %.
::

## Normalfordeling

I mange store datasett ligger de fleste verdiene nær gjennomsnittet og færre langt unna. Da får fordelingen en klokkeform – vi sier den er **normalfordelt**.

::plot x=140,215 y=0,0.055 xs=10 ys=0.01 h=240 xl=\text{høyde_(cm)} yl=\text{} nonum
f: exp(-((x-177)^2)/(2*64))/(8*sqrt(2*3.1416)) | label=\text{normalfordeling}
area: exp(-((x-177)^2)/(2*64))/(8*sqrt(2*3.1416)) | 0 | 169,185
vx: 177 | dash
::

::regel Omtrent 68 %
I et normalfordelt datasett ligger omtrent **68 %** av observasjonene innenfor **ett standardavvik** fra gjennomsnittet, og omtrent 95 % innenfor to standardavvik.
::

::eks Oscar målte bussreisen i to uker: uke 1: 25, 23, 22, 22, 24 min og uke 2: 42, 25, 24, 24, 22 min. Finn gjennomsnitt og standardavvik, og sammenlikn.
---
Uke 1: $g = 23{,}2$ min, $\sigma \approx 1{,}17$ min. Uke 2: $g = 27{,}4$ min, $\sigma \approx 7{,}36$ min.

Standardavviket er mye større i uke 2. Det skyldes særlig den ene turen på 42 minutter.
::

::tips Standardavvik med Python
```python
from statistics import mean, pstdev
x = [1, 2, 3, 4, 5, 6]
f = [2, 5, 8, 7, 4, 1]
data = []
for verdi, antall in zip(x, f):
    data = data + [verdi] * antall
print("Gjennomsnittet er", round(mean(data), 2))
print("Standardavviket er", round(pstdev(data), 2))
```
Programmet gir 3.33 og 1.25. Bruk `pstdev` (populasjon), som tilsvarer `STDAV.P` i regneark.
